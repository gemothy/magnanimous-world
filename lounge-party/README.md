# Liar's Lounge

A cast-to-the-television party game set in the Magnanimis. The TV is the table; everyone's
phone is their hand. Bluffing, calling each other liars, and a row of six tiki mugs where
one of them is the bad one.

```bash
npm install
npm start
```

- **Television** — `http://localhost:7777/tv` (opens a new table, displays a four-letter code)
- **Phone** — `http://localhost:7777/play` (enter the code)
- **Tests** — `npm test` (rules engine) and `node server/test-e2e.mjs` (full socket protocol)

To play on real phones, serve on your LAN and point them at `http://<your-ip>:7777/play`.

---

## Why it is built this way

**The Cast SDK is not how players connect.** The Web Sender SDK only runs on desktop Chrome
and Android — `tiki-lounge`'s own README says so. A party game that excludes every iPhone in
the room is dead on arrival, so the Chromecast is used purely to get the television view on
screen, and the game networking is entirely separate:

```
Chromecast ──displays──► /tv ──┐
                               ├──► game server (rooms, hands, turns)
Phones ──open /play, type code─┘
        any phone, any browser, no app, no Cast SDK
```

This is the Jackbox model, and it is why Jackbox works on every phone ever made.

## Shape

| | |
|---|---|
| `shared/game.mjs` | The entire game. A pure reducer — no sockets, no DOM, no timers, no clock. |
| `server/server.mjs` | Rooms, sockets, and the security boundary. **The only file that knows about transport.** |
| `tv/index.html` | The television. Renders `publicView` and dramatises events. |
| `phone/index.html` | The controller. Renders `privateView` for one player. |

**The reducer is deliberately pure.** `reduce(state, action) -> {state, events}` with an
injected seed and no side effects, which is why the whole game is testable in a second from
node with nothing running, and why a bug someone hits on a couch can be replayed exactly from
its seed. Moving to PartyKit, Durable Objects or a hosted socket service means rewriting
`server.mjs` and nothing else.

**`events` exist because state is not enough.** State says what is true now; events say what
just happened. The television needs the latter to know when to flip cards over and flash the
screen.

## The security boundary

This is a hidden-information game, so it only works if the hidden information is actually
hidden. Two projections enforce that, and they are the reason hands are never leaked:

- `publicView(state)` → the television. Hand **counts** only, never cards. No mug positions.
- `privateView(state, playerId)` → one phone. That player's hand and nothing about anyone else.

The server picks which one each socket gets in `broadcast()`. It is not possible to
accidentally send a hand to the television, because the television's payload is built by a
function that cannot produce one.

Identity is taken from the socket, never from the message: `action.playerId = ws.playerId`.
A phone cannot act as another player even if it forges the field. Both properties are
asserted in `test-e2e.mjs` — including an explicit spoofing attempt and a scan of the
television's wire format for `"rank"`.

## The game

Three ranks (Orchid, Tiki, Skull) plus two wilds. Five cards each. A rank is declared for the
round.

On your turn you place one to three cards **face down** and claim they are all that rank. The
next player either believes you and plays their own, or calls **Liar**. The cards turn over:
if they were honest the challenger was wrong, otherwise the player was. Whoever is wrong goes
to the bar, where six mugs are waiting and one of them is the bad one. Survive and that mug is
removed — the odds tighten every single time. Last player at the table wins.

The pacing is owned by the **television**, not the model: `roundEnd` sits for 4.2s before the
TV requests the next deal, so a reveal has room to land. Phones own intent; the screen owns
drama.

## Assets

Symlinked, not copied — `tiki-lounge` and `gone-away` stay the sources of truth:

- `assets/video` → the midnight-lagoon loop the Cast receiver already uses
- `assets/audio` → the 65-track Beach Noir Revue
- `assets/library.json` → the catalogue, generated by `gone-away/scripts/build-library.mjs`

## Not done yet

- **Casting.** The TV view is a plain page; wiring it into the existing CAF receiver at
  `tiki-lounge/public/cast-receiver/` is the next step, and mostly involves pointing the
  receiver at this URL.
- **Host controls** — skip track, volume, kick a player, restart.
- **Reconnect flow.** Seats are held on disconnect and identity persists in `localStorage`,
  but the phone does not yet auto-rejoin on reload.
- **Deployment.** Runs locally on `ws`. Vercel cannot hold websockets, so this needs
  PartyKit / Durable Objects / a small container — one file's worth of change, deliberately.
- **The 3D lounge.** The TV currently uses the pre-rendered lagoon video, which is genuinely
  better looking than the realtime scene and costs a Chromecast almost nothing. `gone-away`'s
  Three.js lounge is the upgrade path if the table ever needs to be interactive.
